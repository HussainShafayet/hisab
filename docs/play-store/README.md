# Google Play

Everything for publishing Hishab (package `com.hishab.app`) to Google Play.

| File | What |
| --- | --- |
| `release-checklist.md` | The upload key, building the bundle, and every step in Play Console |
| `store-listing.md` | Name, descriptions (English and Bangla), settings, graphics |
| `privacy-policy.md` | The policy to put on the web (fill in your contact email) |
| `data-safety.md` | Answers for Data safety and the other declarations |
| `assets/` | 512 px icon and 1024 x 500 feature graphic |
